# Example Mod

A small Fabric quality-of-life mod for Minecraft 1.20.x.

## Installation

1. Install Fabric Loader for Minecraft 1.20.x.
2. Extract this folder with 7-Zip/WinRAR, then run setup.exe.
3. Copy `mods/ExampleMod-1.0.0.jar` into your `.minecraft/mods` folder.
4. Launch Minecraft with the Fabric profile.

## Build from source

```
gradlew build
```
